# CMU branding

These original PNG files were downloaded from City of Malabon University's official website on October 10, 2026. They are served locally so the application's branding does not depend on an external connection.

- `cmu-logo.png`: the full university logo, matching the supplied reference, used on the login, registration, and administrator setup forms. Source: https://cityofmalabonuniversity.edu.ph/wp-content/uploads/2021/04/cmu-logo.png
- The supplied-reference `cmu-logo.png` is also used on both dashboards, system headers, and the favicon. The alternate `cmu-crest.png` from an earlier update is retained as an unused asset; it is not displayed by the application.

The artwork is unchanged. Its colors and proportions are preserved when displayed.
